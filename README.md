# 🎰 GGamble

Eine Spielhalle im Browser – nur mit Spielgeld: Automaten mit Freispielen und Jackpots, Rubbellose zum echten Freirubbeln, Sportwetten, eine Börse mit Hebel und Stop Loss, Minispiele, eigene Geschäfte und Video-Räume mit deinen Freunden. Fang mit 500 € Spielgeld an und werd zum Milliardär!

## ▶️ Jetzt spielen

👉 **https://tillwassenhoven1-glitch.github.io/GGamble/**

Keine Installation, keine Werbung, keine Käufe, kein echtes Geld – läuft auf Handy, iPad und PC. 🎮
Version 0.2.5 · Open Beta

## 🔐 Konto

- 👤 Beim ersten Start legst du ein Konto mit **Name + Passwort** an (ohne Google, ohne E-Mail)
- 💾 Du bleibst eingeloggt – dein Spielstand wird im Browser gespeichert
- 👥 Mehrere Konten auf einem Gerät? Einfach abmelden und mit einem anderen Namen anmelden
- 📋 Neues Gerät? In den Einstellungen den Spielstand-Code kopieren und auf dem neuen Gerät beim Login „Konto von anderem Gerät holen“ tippen

## So funktioniert's

- 🎁 Jeden Tag gibt's den **Tagesbonus** am Glücksrad (1× bis 5×) – je länger deine Serie, desto mehr
- 🎰 Spiel an den Automaten, rubbel Lose, tipp auf Spiele oder handel an der Börse
- 📈 Mit jedem Einsatz sammelst du XP – höhere Level schalten neue Automaten und Lose frei
- 💸 Pleite? Du darfst bis **−180 € ins Minus** (0,5 % Zinsen pro Stunde). Darunter wird dein Konto gesperrt
- 🔓 Raus aus den Schulden: Minispiele spielen, die Schulden ans **Inkasso Krause** verkaufen (Schuldschein über 130 % – bei jedem Spin gehen 10 % vom Einsatz und 40 % jedes Gewinns automatisch dorthin) oder **Privatinsolvenz** anmelden

## 🌐 Online-Bestenliste einrichten (einmalig)

1. https://console.firebase.google.com → **Projekt hinzufügen** (kostenlos)
2. Im Projekt: **Web-App hinzufügen** (`</>`) → `apiKey` und `projectId` kopieren
3. **Build → Firestore Database → Datenbank erstellen** → bei **Regeln** das hier einfügen und veröffentlichen:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /konten/{id} {
      allow get, delete: if true;
      allow create, update: if request.resource.data.keys().hasOnly(['data','ts']);
      allow list: if false;
    }
    match /namen/{id} {
      allow get, create: if true;
      allow list, update, delete: if false;
    }
    match /rang/{id} {
      function ok() {
        return request.resource.data.keys().hasOnly(['name','disp','bal','level','color','ts','big','net','bxp','wag','since','best','ach','own','tit','frm','clan','wk','wkk','dv','dk','mv','mk','hist'])
          && request.resource.data.bal is number
          && request.resource.data.bal < 1000000000000000;
      }
      allow read: if true;
      allow create: if ok();
      allow update: if ok() && request.resource.data.name == resource.data.name;
    }
    match /clans/{id} {
      allow read: if true;
      allow create: if request.resource.data.keys().hasOnly(['name','tag','own','ts'])
                    && request.resource.data.tag == id
                    && request.resource.data.name is string && request.resource.data.name.size() <= 24;
      allow update, delete: if false;
    }
    match /chat/{id} {
      allow read: if true;
      allow create: if request.resource.data.keys().hasOnly(['name','disp','txt','ts','clan'])
                    && request.resource.data.txt is string && request.resource.data.txt.size() <= 200;
      allow update, delete: if false;
    }
    match /dm/{id} {
      allow read: if true;
      allow create: if request.resource.data.keys().hasOnly(['von','an','disp','txt','ts','cts','ats'])
                    && request.resource.data.txt is string && request.resource.data.txt.size() <= 300;
      allow update, delete: if false;
    }
    match /duelle/{id} {
      function keysOk() {
        return request.resource.data.keys().hasOnly(['a','b','ad','bd','g','st','s','bi','seed','mv','tn','fi','ac','bc','am','bm','w','ts','t0']);
      }
      allow read: if true;
      allow create: if keysOk() && request.resource.data.st is number && request.resource.data.st >= 1;
      allow update: if keysOk() && request.resource.data.a == resource.data.a
                    && request.resource.data.b == resource.data.b && request.resource.data.st == resource.data.st;
      allow delete: if false;
    }
    match /online/{id} {
      allow read: if true;
      allow create, update: if request.resource.data.keys().hasOnly(['ts','n']) && request.resource.data.ts is int;
      allow delete: if false;
    }
    match /gifts/{id} {
      allow read: if true;
      allow create: if request.resource.data.keys().hasOnly(['to','amt','ts','msg','sig','von','k','x']) && request.resource.data.amt is number;
      allow update, delete: if false;
    }
    match /feed/{id} {
      allow read: if true;
      allow create: if request.resource.data.keys().hasOnly(['name','disp','txt','ts','clan'])
                    && request.resource.data.txt is string && request.resource.data.txt.size() <= 120;
      allow update, delete: if false;
    }
    match /lbsperre/{id} {
      allow read: if true;
      allow create: if request.resource.data.keys().hasOnly(['n','h','ts','sig']) && request.resource.data.n is string;
      allow update, delete: if false;
    }
  }
}
```

4. In der `index.html` die Zeile `const ONLINE = { apiKey: '', projectId: '' };` mit deinen Werten füllen

Solange da nichts steht, zeigt die Bestenliste nur die Konten auf dem eigenen Gerät.
